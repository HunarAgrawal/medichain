# Medichain demo

A live demo of [Medichain](https://github.com/HunarAgrawal/medichain): radiology reporting for
hospitals, imaging centres and teleradiology, with an AI pre-read, radiologist sign-off, instant
delivery and QR-verifiable reports.

**Open the app in its own tab** at `https://<owner>-<space>.hf.space`. Sign-in uses a cookie,
which browsers block inside the embedded frame on this page.

This is a fictional hospital with invented patients. The workspace is rebuilt every time the
Space restarts, so anything you add is temporary. Not for clinical use.
